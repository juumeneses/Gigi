# Piloto reduzido: uma imagem, 11 propostas

Seis propostas anteriores preservadas; cinco referencias visuais 2D adicionadas. Os novos pontos nao sao equivalentes anatomicos validados de zy, pg, gn ou mo. Malar representa uma regiao, ainda sem regra de repetibilidade validada. Todas as coordenadas sao propostas de IA, nao verdade de treino. Revisao visual favoravel nao comprova precisao anatomica. Lados seguem o cranio, pressupondo imagem nao espelhada.
