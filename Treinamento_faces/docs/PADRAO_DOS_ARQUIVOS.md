# Padrão dos arquivos

Nesta etapa, o pacote usa somente as imagens de face `FFN`.

Formato esperado:

```text
ANO_NUMERO_INICIAIS_TIPO.ext
```

Exemplo:

```text
2023_39_DADP_FFN.jpg
```

Campos:

- `ANO`: ano da base, por exemplo 2023.
- `NUMERO`: número da amostra/paciente.
- `INICIAIS`: iniciais da pessoa.
- `TIPO`: `FFN` para face frontal neutra; `CF` será usado depois para crânio.
- `ext`: jpg, jpeg ou png.
